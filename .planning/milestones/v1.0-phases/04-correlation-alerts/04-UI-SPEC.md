## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `slate-950` (dark) / `light.bg #f8fafc` (light) | Page background |
| Secondary (30%) | `slate-900`/`slate-800` (dark) / `light.surface #ffffff` (light) | Cards, list rows, nav, settings inputs |
| Accent (10%) | `brand-400 #599dff` / `brand-500 #3377ff` | Active tab indicator, focus borders, toggle accent |
| Destructive | `bear #dc2626` (dark) / `red-400` (light) | "Clear all" action only |

Accent reserved for: **active tab indicator** (`text-brand-400 border-brand-400`), **focus borders** (`focus:border-brand-400`), **toggle/checkbox accent** (`accent-brand-500`), **alert direction badges** (bull `#16a34a` / bear `#dc2626` / neutral `#6b7280`). Do NOT use accent for generic list text or backgrounds.

**Direction color contract (ALERT-02):**
- Bullish → `bull #16a34a` (green) — badge + direction arrow ▲
- Bearish → `bear #dc2626` (red) — badge + direction arrow ▼
- Mixed → `neutral #6b7280` (gray) — badge + direction arrow ◆

**Theme-aware helpers:** Reuse the existing `isDark` pattern from `App.tsx` (`bgClass`, `headerBg`, `tabActive`, `tabInactive`, `sectionTitle`). All new Alerts-tab elements must render correctly in both `dark` and `light` classes.

**Focal point (visual priority):** The **alert list rows** — specifically their **direction badges** (bull/bear/mixed) — are the primary visual anchor of the Alerts tab. The eye lands first on the direction badge + market name of each row. The **"Clear all"** action is secondary and visually de-emphasized: rendered as a muted/destructive text button in the tab header, never accent-colored, so it does not compete with the alert content.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Clear all** (verb + noun, from D-10) |
| Empty state heading | **No alerts yet** |
| Empty state body | Alerts appear here when a watchlisted market shows a new or changed correlation. |
| Error state | **Couldn't load alerts.** Check your connection and try again. |
| Destructive confirmation | **Clear all alerts?** — two-step inline confirm: button label changes from "Clear all" to "Confirm clear?" on first click; reverts after 3s or on cancel. |

**Alert record copy (per alert row):**
- Direction label: **Bullish** / **Bearish** / **Mixed**
- Market name: the watchlisted contract's display name
- Top signal/news: the single strongest correlated signal headline or news headline
- Timestamp: relative time (e.g. "2h ago") with absolute tooltip

**Settings copy (popup):**
- Toggle label: **Correlation alerts** — helper: "Notify me when a watchlisted market shows a new or changed correlation."
- Cooldown label: **Alert cooldown (minutes)** — helper: "Minimum time between alerts for the same market (default: 60)."
