<objective>
Route the three keyword-overlap ML engines — zeroshot, sentiment, and LLM — through the shared `InvertedIndex` candidate pre-filter, replacing their ad-hoc `filter`+`slice`/`filter`+`continue` blocks, and prove equivalence with per-engine equivalence test files.

Purpose: These three engines already require keyword overlap for a match, so the inverted index is a provably valid superset of their naive matches. Routing them through the shared index gives a single tokenization source, one place to test, and consistent behavior (D-01, D-04).
Output: `src/services/engine/ml/zeroshot.ts`, `sentiment.ts`, `llm.ts` (candidate-filtered via the index), plus `zeroshot-equivalence.test.ts`, `sentiment-equivalence.test.ts`, `llm-equivalence.test.ts`.
</objective>
