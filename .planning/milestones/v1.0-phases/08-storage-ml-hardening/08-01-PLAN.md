<objective>
Enforce the per-key storage caps (`maxSignals`, `maxNews`, `maxMarkets`) at write time in the merge helpers, so no single collection key can grow unboundedly (PERF-03, D-01).

Purpose: The caps are defined in `CONFIG.storageBudget` but never enforced — they exist only as documentation. A single runaway key (e.g., a burst of news) could blow the 7 MB budget before the byte-budget pruner runs. Enforcing at write time bounds each key independently and complements the existing byte pruner.

Output: A shared `capByOldest` helper + cap enforcement in `mergeSignals`/`mergeNews`/`mergeMarkets`, plus unit tests proving the caps work.
</objective>
