<objective>
Make `getBytesInUse()` the authoritative storage-budget measure and add incremental per-key byte tracking, so the budget aligns with Chrome's real UTF-16 serialization and pruning no longer re-serializes the whole dataset (PERF-03, D-02, D-03).

Purpose: `estimateBytes` (UTF-8 Blob) diverges from `chrome.storage.local`'s real UTF-16 serialization, so a budget tuned to it can overflow the real quota. And pruning currently re-serializes the whole store every cycle. `getBytesInUse()` is cheap and exact; incremental deltas avoid the O(store) cost.

Output: `measureStorageUsage()` backed by `getBytesInUse()`, incremental per-key byte tracking reconciled periodically, and pruning using incremental deltas.
</objective>
