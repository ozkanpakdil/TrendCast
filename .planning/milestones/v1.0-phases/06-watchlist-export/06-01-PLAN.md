<objective>
Add a `version` field to `WatchlistEntry` and backfill old stored records on read, so existing watchlist data loads without crashing after the schema change (D-08).

Purpose: D-08 requires a version field on `WatchlistEntry` with backfill-on-read so old stored data (which lacks the field) loads without crashing. </objective>
