<objective>
Add a settings migration that backfills missing source flags into persisted storage on load, so the deep-merge fix persists across restarts.

Purpose: Fixes NEWS-02. The deep-merge in plan 09-01 fixes the in-memory read, but the stored settings object still lacks the newer source flags. Without a migration, the fix only applies while the merged value is in memory and would be lost on the next write. A migration backfills the missing flags into `chrome.storage.local` once, mirroring the existing `migrateTikTokDefault()` pattern.

Output: A pure, unit-testable `migrateEnabledSources()` helper in `src/utils/settings.ts`, wired into the background install/update handler, plus its unit test.
</objective>

    In `src/utils/settings.ts`, add a pure function `migrateEnabledSources(stored: Partial<ExtensionSettings> | undefined): Partial<ExtensionSettings> | null`. Behavior: if `stored` is `undefined` or `stored.enabledSources` is not a plain object, return `null` (nothing to migrate). Otherwise compute the backfilled `enabledSources` as `{ ...stored.enabledSources, ...DEFAULT_SETTINGS.enabledSources }` — note the order: stored keys win, defaults only fill missing keys. If the result is deep-equal to `stored.enabledSources` (i.e. no key was missing), return `null` (idempotent — nothing changed). Otherwise return a new object `{ ...stored, enabledSources: backfilled }` that the caller persists. This never overwrites an explicit user preference (present keys win) and only adds missing source flags. Keep the module pure — no `browser` or `CONFIG` imports.

    Create `tests/unit/settings-migration.test.ts` (Vitest, globals enabled, no browser mock needed). Cover at minimum: (1) `undefined` stored returns `null`; (2) a stored `enabledSources` missing `seekingalpha`/`investing`/`googleFinance` returns a new object with those three flags `true` and all other stored keys preserved; (3) an explicit `seekingalpha: false` in stored is preserved (not flipped to `true`); (4) a fully-populated `enabledSources` returns `null` (idempotent — no change); (5) a non-object `enabledSources` (e.g. a string) returns `null` without throwing.
