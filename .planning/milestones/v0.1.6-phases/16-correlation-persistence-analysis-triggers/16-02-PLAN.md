<objective>
Make collection completion trigger correlation re-analysis in the open dashboard: a storage.onChanged listener on the snapshot keys fires a guarded re-run (skip when a run is live/queued, skip when the stored analysis is already as fresh as the snapshot), completing TRIG-03.

Purpose: The second half of Phase 16 — after collectNow lands a new snapshot, the open dashboard re-analyzes without a manual click, without double-running the ML engine, and without re-running when the stored result already covers the new data.

Output: shouldTriggerReanalysis pure guard + unit tests, the onChanged listener effect in useCorrelations, and two e2e tests proving trigger-on-collection and no-double-run. No new npm packages.
</objective>
