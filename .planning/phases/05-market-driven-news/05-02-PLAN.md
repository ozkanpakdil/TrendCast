<objective>
Build the pure aggregation module `buildMarketDrivenNews` that turns existing markets + `correlations.newsMatches` + the watchlist into a bounded, category-grouped `marketNewsView` snapshot, and wire it into the background after each correlation completes.

Purpose: MKT-01 requires a "market-driven news" view — important markets → news/direction they imply. D-05..D-09 lock the notable-market filter, direction computation, sort, and category grouping. D-11/D-13/D-15 require the derived snapshot be written to storage after each correlation. This plan is the read-only derived projection over existing data — no new collection.

Output: `src/background/correlationNews.ts` (types + `buildMarketDrivenNews`), wiring in `src/background/index.ts`, and `tests/unit/correlation-news.test.ts`.
</objective>

    - Test 3 (category grouping, D-09): items are grouped into `categories.finance/politics/technology`; a contract's category derives from the majority category of its correlated news, falling back to `classifyCategory(contract.question)`
    - Test 4 (sort + cap, D-08/D-14): within each category, items are sorted by volume24h descending and sliced to capPerCategory
    - Test 5 (watchlist inclusion): a watchlisted contract with no volume still appears
    - Test 6 (backfill, Pitfall 2): a NewsItem without `category` is classified on read from its headline
  </behavior>
  <action>
    Create `src/background/correlationNews.ts` as a pure aggregation module (ARCHITECTURE.md Pattern 4, extended for category + watchlist + cap). Export:
    - `export interface MarketDrivenNewsItem` with fields: `contract: MarketContract`, `category: NewsCategory`, `direction: 'up' | 'down' | 'mixed'`, `news: NewsCorrelationMatch[]`, `signalCount: number`, `volume24h: number`.
    - `export interface MarketNewsView` with fields: `builtAt: number`, and `categories` as a `Record` keyed by `NewsCategory` whose values are `MarketDrivenNewsItem[]`.
    - `export function buildMarketDrivenNews(newsMatches: NewsCorrelationMatch[], watchlist: WatchlistEntry[], minVolume: number, capPerCategory: number): MarketNewsView`

    Algorithm:
    1. Build a `Set` of watchlisted contract IDs from `watchlist`.
    2. Filter `newsMatches` to contracts that are notable: `(contract.volume24h ?? 0)` is at or above `minVolume` OR watchlisted (D-05). Omit contracts with no correlated news — the view is "market-driven **news**" (Open Question 1 recommendation). The `markets` list is NOT a parameter — each `NewsCorrelationMatch` embeds its full `MarketContract`, so the aggregation derives everything from `newsMatches` alone (no dead/unused parameter).
    3. Group the filtered matches by `contract.id` into `MarketDrivenNewsItem`s.
    4. Compute `direction` per contract (D-07): reuse the `yesPriceOf` helper pattern from `alerts.ts` (find the outcome whose label is `'yes'`); compute mean news sentiment via `sentimentScore(match.news.headline)` from `@/utils/sentiment` (NewsItem has no persisted sentiment — compute on demand). `direction = sign(yesPrice - 0.5)` blended with `sign(meanSentiment)`; if the sum is positive → 'up', negative → 'down', else 'mixed'.
    5. Assign `category` per contract: derive from the majority category of its correlated news items (each `NewsCorrelationMatch.news.category`, backfilled via `classifyCategory(news.headline)` when undefined — Pitfall 2), falling back to `classifyCategory(contract.question)` when no news has a category.
    6. Sort each category's items by `volume24h` descending (D-08), then `slice(0, capPerCategory)` (D-14).
    7. Return the `MarketNewsView` grouped by category (D-09), with `builtAt: Date.now()`.
    Do NOT hardcode any category keyword list here — import `classifyCategory`, `CATEGORY_ORDER`, `NewsCategory` from `@/config/taxonomy` (Pitfall 3 anti-pattern). Do NOT write to storage in this pure function — storage persistence is Task 2.
    Extend `tests/unit/fixtures.ts` with shared `MarketContract`/`NewsItem`/`NewsCorrelationMatch` fixtures (reuse `mockContract`, `newsItem()`; add a `newsMatch(contract, news, confidence)` helper). Create `tests/unit/correlation-news.test.ts` covering the behaviors above.
