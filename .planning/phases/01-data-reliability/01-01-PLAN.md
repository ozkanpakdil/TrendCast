## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| background collector → storage | The collector writes `sourceHealth` into `chrome.storage.local`; the dashboard reads it read-only. |
| storage → dashboard | `sourceHealth` is read by the dashboard; it must be treated as untrusted data (validated against the `NewsSource` union). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-1-02 | Tampering | `sourceHealth` in storage | low | accept | Health is written only by the background collector; the dashboard reads it read-only. No user-writable path exists. |
