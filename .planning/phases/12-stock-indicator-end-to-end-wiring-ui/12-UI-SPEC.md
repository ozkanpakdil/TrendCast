# Phase 12 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase type: UI WIRING (extend existing maps, no new components).** Phase 12 makes the three stock-indicator sources (`usaStocksIndicator`, `stockScreener`, `stockScreener2`) toggleable in the popup settings and labeled/colored consistently across the dashboard. The design system is fully established; this contract EXTENDS the existing source-label/color maps and the settings toggle list. It does not invent new design tokens, new components, or new layout. `SourceHealthIndicator.tsx` already has the three sources (done in Phase 11) — this phase adds them to `NewsFeed.tsx`, `HistoryChart.tsx`, and `Settings.tsx`.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#020617` (slate-950, dark) / `#f8fafc` (light) | Dashboard background |
| Secondary (30%) | `#1e293b` (slate-800) / `#334155` (slate-700) | Cards, tile borders (`border-slate-800`), settings toggle rows (`bg-slate-800`) |
| Accent (10%) | `#3377ff` (brand-500) | Reserved for: checkbox accent (`accent-brand-500`), interactive links, focus states |
| Destructive | `#dc2626` (bear) | Destructive actions only — none in this phase |

**Accent reserved for:** checkbox accent in settings toggles, interactive links, focus rings. Not for news tiles.

**News tile palette** (content tiles, NOT UI chrome — distinct from the 60/30/10 split; already in `NewsFeed.tsx`). The three NEW source colors are added to the existing `sourceColor` palette and `textColor` map:

| Source | Tile bg | Text | Status |
|--------|---------|------|--------|
| bbc | `rgb(220,38,38)` red | `#ffffff` | existing |
| cnn | `rgb(190,24,93)` rose | `#ffffff` | existing |
| yahoo | `rgb(124,58,237)` violet | `#ffffff` | existing |
| googleFinance | `rgb(16,185,129)` emerald | `#ffffff` | existing |
| seekingalpha | `rgb(245,158,11)` amber | `#0f172a` | existing |
| investing | `rgb(14,165,233)` sky | `#0f172a` | existing |
| **usaStocksIndicator** | `rgb(20,184,166)` teal | `#ffffff` | **NEW** |
| **stockScreener** | `rgb(249,115,22)` orange | `#0f172a` | **NEW** |
| **stockScreener2** | `rgb(217,70,239)` fuchsia | `#ffffff` | **NEW** |
| unknown | `rgb(51,65,85)` slate fallback | `#ffffff` | existing |

**Color selection rationale:** the three new hues (teal, orange, fuchsia) are distinct from all six existing source hues (red, rose, violet, emerald, amber, sky) so tiles remain visually scannable. Text color follows the existing luminance rule: lighter tiles (amber, sky, orange) use dark text `#0f172a`; darker tiles use `#ffffff`.

**HistoryChart `PLATFORM_LABELS`:** add the three new sources to the existing `PLATFORM_LABELS` map (used for the detail-panel news list). No new chart colors — the chart's `METRIC_COLORS` are per-metric, not per-source, and are unchanged.

Source: `tailwind.config.ts`, `NewsFeed.tsx`, `HistoryChart.tsx`. New colors introduced by this phase: teal, orange, fuchsia (tile palette only).

## UI Considerations

> State coverage for the news tab, source-health sidebar, history chart, and settings toggles. This phase must NOT regress any existing state. It only adds three sources to existing maps and the settings toggle list.

Applicable state considerations resolved: 7 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | news list-collection | ✅ covered | Empty results render the documented "No news collected yet. Wait for the next hourly collection." copy (`NewsFeed.tsx`). Adding sources to the label/color maps does not touch this branch. |
| populated | news list-collection | ✅ covered | Populated grid renders all 9 sources via `VirtualizedGrid` with per-source tile colors. The three new sources now resolve to teal/orange/fuchsia tiles instead of the slate fallback. |
| partial | news list-collection | ✅ covered | A source with no items contributes no tiles; the grid renders whatever `news` array contains. Unchanged. |
| long-text | news tile (static-content) | ✅ covered | Headline clamped to 2 lines (`WebkitLineClamp: 2`); summary `line-clamp-1`; source label + timestamp at 9px. Unchanged. |
| overflow | news list-collection | ✅ covered | `VirtualizedGrid` virtualizes the list; tiles have `minHeight: 100px`. Unchanged. |
| zero-one-many | news list-collection | ✅ covered | Zero → empty state; one/many → grid. Unchanged. |
| loading | news list-collection | ✅ covered | Loading handled upstream by the dashboard hook; `NewsFeed` receives a settled array. Unchanged. |
| error | news list-collection | ✅ covered | Error handled upstream by the dashboard hook; `NewsFeed` receives a settled array. Unchanged. |

**Source-health sidebar (`SourceHealthIndicator`):** already done in Phase 11 — `sourceLabels` includes all three new sources, `SOURCE_ORDER` appends them at the end, `sourceDomains` maps all three to `ozkanpakdil.github.io`. No change required this phase. Verify the three badges render with the correct labels and favicons.

**History chart detail panel:** `PLATFORM_LABELS` gains the three new entries so the detail-panel news list shows `Stock Indicator` / `Breakout` / `VCP` instead of raw source keys.

**Settings toggle state:** the `DataSources` section in `Settings.tsx` gains three new checkbox rows. Each row reads `settings.enabledSources[source]` and writes back via the existing `onUpdate({ enabledSources: {...} })` pattern. The popup home-tab source summary chips (`Object.entries(settings.enabledSources).map(...)` in `App.tsx`) already render new sources automatically — no change needed there. Note: `yahoo` and `googleFinance` are NOT in the current toggle list (pre-existing gap, out of scope for this phase — do NOT add them unless the user requests it).
