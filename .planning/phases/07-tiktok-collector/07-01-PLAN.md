<objective>
Implement the empty `src/content/socials/index.ts` to scrape TikTok discover-page trends and report them as `SocialSignal[]` via `REPORT_SOCIAL_DATA`, with debounce, hash dedup, and a `Promise.race` hard timeout (D-01, D-04).

Purpose: SRC-01 requires TikTok social sentiment as a best-effort source. The manifest already injects `src/content/socials/index.ts` on tiktok.com, but the file is empty (0 bytes) — this is the core gap. TikTok has no public API, so DOM scraping on the discover page is the only viable approach. The scraper must be defensive (broad selectors, graceful `[]`) so TikTok DOM fragility never breaks the host page or the collection pipeline.

Output: An implemented `src/content/socials/index.ts`, a pure `normaliseTikTokTrend` helper in `src/utils/tiktok.ts`, and unit tests for the normalizer and scraper.
</objective>
