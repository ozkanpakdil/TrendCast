# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase nature:** Brownfield performance hardening. This contract does NOT introduce new visuals — it **preserves** the existing feed appearance while adding row-based virtualization. The design contract is a "keep it identical" contract: the executor must not change card styling, grid appearance, empty-state copy, or interaction behavior. All values below are extracted from the current codebase (`HypeFeed.tsx`, `NewsFeed.tsx`, `tailwind.config.ts`, `dashboard.css`) and locked as the source of truth.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Keyword chip padding (`px-1.5 py-0.5` ≈ 6/2px), inline gaps (`gap-1`) |
| sm | 8px | Grid gap (`gap-2`), scrollbar width (8px) |
| md | 16px | Section padding (`px-6`), card padding (`p-2.5` ≈ 10px) |
| lg | 24px | Section vertical rhythm (`py-6`, `py-8` empty-state) |
| xl | 32px | Layout gaps (nav `gap-1` is 4px; xl reserved for future) |
| 2xl | 48px | Major section breaks (reserved) |
| 3xl | 64px | Page-level spacing (reserved) |

**Exceptions (existing, must be preserved):**
- Card padding `p-2.5` = **10px** (not on the 4px scale — existing, do not change).
- Card `minHeight: 100px` (inline style, not a Tailwind token).
- Virtualizer row estimate **120px** = card minHeight (100px) + grid gap (8px) + margin allowance (12px). This is a runtime estimate, not a design token.
- Virtualized scroll container height: `max-h-[70vh]` (matches `MarketOdds` treemap's existing `height: 70vh` convention).

## Typography

| Role | Size | Weight | Line Height | Source |
|------|------|--------|-------------|--------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Empty-state copy, section labels |
| Label | 11px (`text-[11px]`) | 600 | 1.2 | Keyword chips, card headline (`font-semibold`) |
| Micro | 9px (`text-[9px]`) | 700 | 1.2 | Platform/source label, virality number, author, timestamp, engagement |
| Heading | 14px (`text-sm`) | 700 | 1.2 | Section titles (`font-bold uppercase tracking-wider`) |

**Weights declared:** 400 (regular) + 700 (bold). The 600 (`font-semibold`) used on card headlines is a **minor existing exception** — it is the card title weight and must be preserved as-is; do not introduce additional weights.

**Line-height:** Body 1.5; card text uses `leading-tight` (1.25) with `line-clamp-2` — preserve exactly.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (slate-900) dark / `#f8fafc` (light-bg) light | Page background, scrollbar track |
| Secondary (30%) | `#1e293b` (slate-800) dark / `#ffffff` (light-surface) light | Card borders (`border-slate-800`), scrollbar thumb |
| Accent (10%) | `#3377ff` (brand-500) | **Reserved for:** hot-signal card border (`border-brand-500/40`) + glow shadow (`shadow-brand-500/10`). Nothing else. |
| Destructive | `#dc2626` (bear) | Destructive actions only — **none in this phase** |

**Accent reserved for:** hot-signal highlight border + glow on `HypeFeed` cards only. Do not use brand blue for feed backgrounds, links, or hover states.

**Semantic tile colors (NOT the accent — preserve exactly):**
- `HypeFeed` tiles: sentiment heat gradient (green `#16a34a` → slate → red `#dc2626`) via `heatColor()`.
- `NewsFeed` tiles: per-source palette (BBC red, CNN rose, Yahoo violet, Google emerald, Seeking Alpha amber, Investing.com sky) via `sourceColor()`.
- Text on tiles: `#ffffff` or `#0f172a` (dark text on amber/sky) via `textColor()`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **None — read-only phase.** No user-initiated actions are added or changed. |
| Empty state heading | `HypeFeed`: "No social signals collected yet." / `NewsFeed`: "No news collected yet." |
| Empty state body | `HypeFeed`: "Visit X, Reddit, or TikTok to collect data, or wait for the next hourly collection." / `NewsFeed`: "Wait for the next hourly collection." |
| Error state | **None in this phase.** Feed error handling is out of scope (source health errors live in `SourceHealthIndicator`, Phase 1). |
| Destructive confirmation | **None.** No destructive actions exist in the feed components. |

**Empty-state rendering rule (MUST):** The empty state must render as an **early return before the virtualizer** (`if (sorted.length === 0) return <p>…</p>`). The virtualizer with `count: 0` renders nothing — the empty message must never be inside the virtualized window. Copy is unchanged from current source.

## UI Considerations

Applicable state considerations resolved: **8 covered, 0 backstop, 0 unresolved**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | HypeFeed / NewsFeed list | ✅ covered | Empty arrays render the documented empty-state copy via early return before the virtualizer (existing behavior preserved) |
| loading | Dashboard | ✅ covered | Handled by `App.tsx` `loading` gate (out of scope for this phase — no change) |
| error | HypeFeed / NewsFeed list | ✅ covered | Feed error handling is out of scope — source-health errors live in `SourceHealthIndicator` (Phase 1). No new error surface introduced. |
| populated | HypeFeed / NewsFeed list | ✅ covered | Happy path renders the virtualized grid; only visible rows are in the DOM (`overscan: 3` for smooth pre-scroll) |
| partial | HypeFeed / NewsFeed list | ✅ covered | Variable-height cards handled by `measureElement` + `data-index`; partial rows render normally with `line-clamp` truncation |
| overflow | HypeFeed / NewsFeed list | ✅ covered | Virtualization bounds DOM to visible rows only; scroll container `max-h-[70vh] overflow-y-auto` gives the virtualizer a bounded viewport |
| zero-one-many | HypeFeed / NewsFeed list | ✅ covered | Single item renders as one row of 1 card; many items render only visible rows (virtualizer `count = rows.length`) |
| long-text | Card headline / summary | ✅ covered | `line-clamp-2` on headlines, `line-clamp-1` on news summary — preserved unchanged; `measureElement` corrects variable row heights |

**Interaction contract (success criteria mapping):**
- **Scroll without jank:** Only visible rows in DOM; `overscan: 3` rows rendered beyond viewport for smooth pre-scroll.
- **Tab-switch without delay:** Feeds are `memo`-wrapped (D-03); `App.tsx` mounts tabs lazily via `{activeTab === 'x' && …}` — unchanged. Virtualization reduces mount cost of feed tabs.
- **Click/filter/hover without freeze:** Card hover (`card-hover` class) and click-through (`<a>`/`<div>` wrapper) behavior preserved exactly; only visible cards exist so hover/click targets are bounded.
