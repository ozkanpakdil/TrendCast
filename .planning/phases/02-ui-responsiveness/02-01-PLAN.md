## Phase Goal

**As a** TrendCast user, **I want to** scroll through the news and social feeds without lag when large datasets are loaded, **so that** I can interact with the dashboard without the UI freezing during rendering.

## Objective

Virtualize the two list feeds (`HypeFeed`, `NewsFeed`) using **@tanstack/react-virtual** so only visible rows are in the DOM. This eliminates the jank source (hundreds of DOM nodes rendered at once) while preserving the exact grid appearance, empty-state copy, and interaction behavior.

**Purpose:** PERF-01 — user can interact with the dashboard without lag when rendering large datasets (scroll without jank, tab-switch without delay, click/filter/hover without freeze).

**Output:** A shared row-virtualized grid helper, both feeds rewired through it, and unit + e2e tests proving bounded DOM.

## Acceptance Criteria

- [ ] `@tanstack/react-virtual@^3.14.10` added to `package.json` dependencies via `bun add` (Bun only, never npm/npx)
- [ ] `HypeFeed` and `NewsFeed` render only visible rows; DOM node count is bounded with a large dataset
- [ ] Empty-state copy preserved via early return before the virtualizer
- [ ] Card styling, grid appearance, and interaction behavior unchanged
- [ ] `MarketOdds`/`CorrelationPanel` untouched (D-02); no extra memoization or App.tsx state splitting (D-03)
- [ ] Existing feed e2e assertions updated from `main .grid > *` to the dedicated `main .card-hover` card selector; bounded-DOM test counts cards (same element type)
- [ ] Unit tests for `chunk` + `getColumnCount`; e2e tests for bounded DOM + scroll reveal + News-tab interactivity
